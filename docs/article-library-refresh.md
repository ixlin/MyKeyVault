# 公众号资料库更新（2026-10-04）

## 本次交付

- 移除「安全」下拉、受控使用/连接凭据页面和受控调用接口。不关闭密码本加密、身份校验或安全审计；旧表保留，避免删除历史数据。
- 文章列表支持搜索、30 条分页、抓取百分比、阶段时间线、失败原因和重试。新任务保存最近 60 个处理阶段；旧任务没有日志时明确说明，不伪造进度历史。
- 后台每 5 秒同步任务，浏览器每 2.5 秒增量更新，不再整页刷新。抓取服务重启导致任务丢失时给出可重试提示。
- 单篇文章的萃取改为对话：Markdown 实时排版、连续追问、独立对话历史、停止生成、下载 Markdown。追问发送最近 8 轮已完成上下文，单轮历史结果最多 6000 字符；文章正文最多 120000 字符。
- 原有萃取各自转成一条独立对话；保留原提问和结果。长期停在 processing 的任务改为失败并保留部分结果，可重新发送。
- 手机端折叠历史栏，触摸按钮增大、文本换行；桌面端左侧历史、右侧对话。

## 安全和资源边界

- 文章、对话、下载和原文静态资源均校验所属用户，不能只凭「已登录」读取其他账号文件。
- 页面 no-store、CSRF、CSP；Markdown 禁用原始 HTML 并经标签/链接白名单清洗，不加载外部跟踪图片。
- AI Key 沿用 AES-256-GCM 信封加密，不回显、不写日志。Base URL 仅允许 HTTPS；连接时校验并固定公网解析 IP，禁止内网地址及跳转。
- 同一用户最多一项进行中的萃取、10 篇排队文章。抓取服务同一时间只启动一个浏览器，减少小内存服务器压力。
- 模型请求上限 5 分钟；中断、停止或失败保留已有回复，不伪装为完成。
- 当前默认模型为官方 `deepseek-flash`，已有账号配置不自动覆盖，账号之间不共享 Key。
